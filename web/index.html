The loop

Issues in.
Pull requests out.

01

Install & subscribe

One static binary — bring gh, git and your own agent harness. mago register starts a 48-hour no-card trial; mago subscribe continues at €20/month.

02

Connect GitHub

Install the mago GitHub App on your repos, run mago link. A company is a repo — its issues are the backlog.

03

Run the worker

mago serve --relay dials out from your machine — NAT-friendly, no inbound ports. GitHub events wake your agents.

04

File issues

Label an issue mago and the team claims it. Want a plan first? Label mago:clarify, answer in comments, add mago:go.

The org chart

An executive team
that never sleeps.

Each role is a markdown persona you can edit. They read shared skills — learned gotchas — so the company gets cheaper and sharper over time.

CTO

Picks up engineering tasks, implements them as clean, tested pull requests. Never merges its own work — separation of duties is enforced by the router.

implements

Head of Org Engineering

Reviews every PR, and merges it once verification passes. Gates intent against the roadmap. In review mode it approves and leaves the merge to you.

reviews

Head of Product

Turns CEO intent into specs and prioritized tasks. Runs the clarify phase.

plans

CMO

Owns positioning, READMEs, landing copy and announcements — marketing, not core code.

comms

You — the CEO

You file issues, answer the rare escalate-to-human question, and approve plans. The rest runs on cadences while you sleep. When nothing is pending, every agent decays to its slowest cadence and the company costs almost nothing.
